Privacy Policy

Last updated: 29 September 2026

Bitcoin Battlefield is a live-streamed visualisation of the Bitcoin market, run by the owner of the YouTube channel @BitcoinBattlefieldTV. This policy covers the "Bitcoin Battlefield Poster" application, which runs only on the channel owner's own computer.

What the application does with Google / YouTube data

The application uses the YouTube Data API, signed in with the channel owner's own Google account, only to operate that one channel:

  • find the channel's current live broadcast, set its title, category and thumbnail;
  • upload short highlight clips (YouTube Shorts) made from the channel's own stream;
  • read the public live chat of the channel's stream, so viewers' commands (for example !bull or !bear) can appear in the game.

It does not access any other user's account, and no one other than the channel owner signs in to it.

Viewers' data

From the public live chat the game uses only a viewer's display name, channel id and the text of commands addressed to the game. It keeps a small score table (display name, points, win streak) on the channel owner's computer and in the owner's own backup, so the leaderboard survives a restart. Free-text chat messages are never shown on screen or stored. Names can be removed on request (see Contact), and viewers banned in the chat are removed from the table automatically.

Storage and sharing

  • Sign-in tokens are stored only on the channel owner's computer.
  • No data is sold, shared with third parties, or used for advertising.
  • No analytics, cookies or trackers are used by the application or this website.

Google API Services User Data Policy

Bitcoin Battlefield's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

YouTube API Services

This application uses YouTube API Services. By watching or taking part in the stream you agree to be bound by the YouTube Terms of Service. YouTube data is handled by Google under the Google Privacy Policy.

Revoking access and deleting data

  • Access granted to the application can be revoked at any time at Google Account → Third-party access. Revoking it stops all further use of the account by the application.
  • Stored YouTube data (the score table above) is deleted when it is no longer needed, and at the latest within 30 days of access being revoked. Daily backups are kept for 30 days and then deleted automatically.
  • To have your name and score removed sooner, email the address below; it is removed within 7 days.

Not financial advice

The stream visualises public market data for entertainment and education. Nothing on the channel or this site is financial advice.
